# Formularios variables por programa

## Documento de explicación para Delta HVAC

### ¿Qué significa “formulario variable”?

La plataforma no utilizará un único formulario rígido para todos los clientes.
Cada programa de incentivos tiene sus propios requisitos, preguntas,
documentos, fotografías, autorizaciones y reglas de revisión. Por eso, el
CRM mostrará automáticamente el formulario correspondiente al programa
seleccionado.

El vendedor no tendrá que decidir manualmente qué información pedir: el
sistema le indicará qué campos completar y qué documentos son obligatorios.

## ¿Por qué es necesario?

Un formulario para Arizona Energy Efficiency puede solicitar información de
la vivienda, miembros del hogar, tipo de propiedad, ingresos o programas
sociales. TECH Clean California puede requerir información diferente para
preaprobación, inspección, equipo y estado de instalación.

Usar un único formulario produciría información incompleta, documentos
incorrectos y retrasos en la presentación de las aplicaciones.

## ¿Cómo funcionará?

1. El vendedor selecciona el programa.
2. El CRM carga las preguntas y requisitos de ese programa.
3. El vendedor registra la información directamente desde el teléfono o
   computador.
4. El cliente revisa la autorización, acepta los Términos y Condiciones y
   firma en ese momento.
5. El sistema valida que la aplicación esté completa.
6. Administración revisa, solicita correcciones si hace falta y somete la
   aplicación al programa.
7. El estado y todas las acciones quedan registrados en el CRM.

## Tipos de información que puede solicitar un programa

- Información personal y datos de contacto.
- Dirección, unidad y tipo de vivienda.
- Propiedad u ocupación del inmueble.
- Características del hogar y composición familiar.
- Programas de asistencia o beneficios existentes.
- Información energética, equipos y medidores.
- Fotografías del inmueble, equipos o condiciones existentes.
- Documentos de identidad, propiedad, elegibilidad o autorización.
- Términos y Condiciones.
- Firma del cliente y firma del vendedor.
- Información necesaria para preparar el invoice del programa.

No todos los programas solicitan los mismos datos. El sistema solo mostrará
los campos aplicables al programa seleccionado.

## Protección y confidencialidad

La información capturada pertenece al proceso de evaluación de elegibilidad y
presentación de la aplicación. Debe utilizarse únicamente para fines
operativos y administrativos de Delta HVAC y del programa correspondiente.

Este documento y los formularios no deben compartirse, copiarse ni
redistribuirse fuera del personal autorizado, los clientes involucrados y las
entidades del programa que deban recibir la aplicación. Las credenciales,
enlaces de firma, documentos y fotografías son información confidencial.

El CRM aplicará permisos por rol, historial de cambios y control de acceso.
La aceptación de T&C y la firma del cliente quedarán asociadas a la versión
del documento, fecha y hora de aceptación.

## Información requerida para configurar cada programa

Para activar un programa en el CRM necesitamos:

- Nombre oficial del programa.
- Formulario o ejemplo vigente.
- Preguntas obligatorias y opcionales.
- Documentos obligatorios.
- Fotografías requeridas.
- Reglas para considerar una aplicación completa.
- Estados utilizados por administración.
- Requisitos de inspección o instalación.
- Estructura del invoice.
- Términos, autorizaciones y textos legales aprobados.

La configuración se hará una vez y el equipo podrá utilizar el formulario
correcto sin mezclar requisitos entre programas.
